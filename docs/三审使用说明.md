# 三审（版式终审）使用说明

三审检查的是**排版后的成品**，不是 Word 稿。它对照《排版标准 260920》检查页面尺寸、版面网格、
字体字号、文字越界、中西混排等问题，并给出带页码和定位的清单。

## 一、准备文件

在 InDesign 里打开排好的文档，导出两份文件：

| 文件 | 导出方式 | 提供什么 |
|---|---|---|
| **IDML** | 文件 → 导出 → InDesign 标记语言（.idml） | 结构：页面尺寸、边距、版面网格、文本框位置、样式 |
| **PDF** | 文件 → 导出 → Adobe PDF（印刷），勾选「使用文档出血设置」 | 成品：实际字体、字号、颜色、位置 |

- 两个都给最准；只给 PDF 也能查字体字号和越界，但查不到版面网格。
- 导出 PDF 时**不要压缩图片**，300dpi 即可，体积不影响判读速度。
- 中文名文件没问题，程序会保留原名。

## 二、在软件里操作

1. 顶部选「三审」环节；
2. 点左侧「①IDML」选择 .idml，点「②PDF」选择 .pdf；
3. 「先用视觉模型判定文字角色」默认勾选——它会看版面判断哪块是作者名、哪块是图注、
   哪块是装饰字，判得更准；关掉则只用字号/字体启发式，不花钱但会粗一些；
4. 点「开始三审」。

耗时参考：10 页约 3 分钟（视觉判定每 2 页拼一张图，5 次调用，3 并发）。
同一份文件重审会命中缓存，不再重复调用。

## 二·五、视觉模型单独配置

如果视觉模型和文本模型不是同一个服务商（很常见），在「设置」里填「视觉模型」：

- **Base URL / Key**：留空 = 沿用主 API；
- **模型**：留空 = 用主 API 的标准模型；
- **每张拼版页数**：默认 2，页数越多调用越省、判读越粗；
- 点「测试视觉模型」会发一张 1×1 图片真实测试，能读图才算通过。

## 二·六、调整《排版要求》

三审的标准可以在「规则库 → 排版要求（三审）」里直接改：

- 页面尺寸、出血、容差、分栏、栏距；
- 网格字体、字号、字间距、行间距、每栏字数、每页行数；
- 正文 / 节标题 / 副节标题 / 作者 / 图注 / 编辑栏 的字号与行距；
- 15 条规则逐条开关（关掉就不出现在报告里）；
- 「恢复默认」随时还原。

改完保存，下次三审生效；配置文件是 `layout_rules.json`（和 config.json 同级，升级不覆盖）。

## 三、看结果

- 左侧：问题清单，按「必改 / 建议改 / 待核实」分组，每条带页码；
- 点击某条意见，右侧页面图会跳到对应页，**红框自动滚到视野中间**并有呼吸动画；
- 右上「显示红框」可随时关掉，方便不挡内容看版面；
- 「− / ＋ / 适宽」调整页面大小：适宽自动铺满可用宽度，＋可放大到 400% 看细节；
- 页面图按 **158dpi（2.2 倍）**渲染并按原像素显示，不会像以前那样被浏览器压缩发糊；
- 右上「导出报告」下载 Markdown 报告，可直接发给排版同事。

## 四、判定口径（重要）

1. **以版面网格为准**（C 为主）：页面 185×260mm、出血 3mm、2 栏、栏距 8mm、
   网格 9 点、字间距 0、行间距 7.5、计 22 字 38 行。
2. **页边距数值不参与判定**：网格起点（下/外 15mm）会造成边距数值与标准表不一致，
   已确认网格本身正确，因此不再拿 20/15/20/15 去卡边距。
3. **按文字角色分别判**：正文 9 点、节标题 12 点、图注 7.5 点、作者 12 点、编辑栏 6 点、
   装饰/首字下沉不套正文标准。角色判定顺序：视觉模型 → IDML 框几何 → 字号/字体族名。
4. **拿不准的进「待核实」**：例如装饰性文字越界、特殊混排，一律标为待核实交人工判断，
   不直接判错。

## 五、已知边界

- `.indd` 二进制文件无法直接解析（Adobe 未公开格式），所以必须导出 IDML；
- 图文遮挡、视觉动线、半透明底图压页码这类**纯视觉问题**，需要看图判断，
  目前只在视觉模型返回了相应区域时才能提示，尚未做成独立规则；
- 视觉结果每次有细微差异，字体混用等硬规则已改为按字号判定，不依赖视觉结果。
