# 二审规则（文字与语法）

> 依据《文稿培训资料 V2.5.0》第八讲（错别字 用词错误）、第九讲（病句）、第十讲（标点符号用法）、第二讲第二节「二审」。
> 二审目标：对文字、语法逐处审查——病句、错别字、专有名词与术语、西文与数字规范、中西文混排、标点。
> 原则：**只报能指到原文的问题；能改就给出改后文字；不擅自改写作者观点与风格。**

## 0 检查顺序
逐句核对：① 病句 → ② 错别字/别字 → ③ 用词与术语 → ④ 标点 → ⑤ 数字、西文与中西混排。

## 1 病句（第九讲）

| 类型 | 典型判据 |
|---|---|
| 语序不当 | 多项定语顺序错（应为：领属/时间处所 → 指称 → 数量 → 动词性 → 形容词性 → 名词）；多项状语顺序错；关联词语位置错（前后分句主语一致时，关联词在主語后）；修饰语与中心语错位 |
| 搭配不当 | 主谓、动宾、定语与中心语、状语与中心语不搭配；一面对两面（"能否""是否"须对应两面表述）；关联词不配对（"不但…而且""只有…才"） |
| 成分残缺或赘余 | 缺主语（"通过…使…""在…中，使…"）、缺宾语中心语、缺介词；语义重复（"大约…左右""再次重申""前来莅临""涉及到""付诸于"）、虚词多余 |
| 结构混乱 | 句式杂糅（"原因是…造成的""本着…为原则""围绕…为核心""是由于…的结果"）、中途易辙、前后牵连 |
| 表意不明 | 指代不明（"他""这个"无明确先行词）、多义歧义、断句歧义、数量表述不明 |
| 不合逻辑 | 自相矛盾、概念并列不当（种属并列、交叉并列）、否定失当（"防止…不再发生"）、强加因果、主客颠倒 |

判定要求：指出属于哪一类，给出改后句子；不要为了"改通顺"而改变原意。

## 2 错别字与用词（第八讲）

### 2.1 的 / 地 / 得
- 定语 + **的** + 名词：敬爱的总理、清清的河水
- 状语 + **地** + 动词：高声地喊、仔细地看、迅速地包围
- 动词/形容词 + **得** + 补语：走得很快、疼得直叫唤、理解得十分深刻
- "de" 后接"很、真、太"等，一般用"得"。

### 2.2 常见易错字（左对右错）
九州—九洲；蛰伏—蜇伏；装帧—装祯；订书机—钉书机；备受关注—倍受关注；战略部署—战略布署；一如既往—一如继往；亭亭玉立—婷婷玉立；歉收—欠收；挖墙脚—挖墙角；一筹莫展—一愁莫展；扯淡—扯蛋；精粹—精萃；震撼—震憾；销假—消假；瘙痒病—搔痒病；人情世故—人情事故；沉湎—沉缅；额手称庆—额首称庆；萎靡不振—萎糜不振；众口铄金—众口烁金。

### 2.3 易混近义词（前者为正/常误用点）
不齿（鄙视）—不耻（不以…为耻）；变换（形式内容更换）—变幻（无规则改变）；处世（社会活动）—处事（处理事务）；定金（担保）—订金（预付款）；法制（制度）—法治（依法治理）；妨害（有害于）—妨碍（阻碍）；供品（供奉用）—贡品（进献帝王）；牟取（贬义）—谋取（中性/褒义）；树立（抽象）—竖立（具体物体垂直）；形迹（举动神色）—行迹（行动踪迹）；泄漏（气液渗出）—泄露（秘密外泄）；义气（江湖情义）—意气（志趣气概）；原形（本来面目，贬）—原型（所依据的现实人物）；淹没（水漫过）—湮没（名声埋没）；作客（寄居他乡）—做客（访问他人）；质疑（提出疑问）—置疑（怀疑，多用于否定）；自诩（自夸，贬）—自许（自期，褒）；终止（结束）—中止（中途停止）；捉摸（猜测，多用于否定）—琢磨（思索、打磨）；配置（配备布置）—配制（按比例混合制造）。

### 2.4 术语与专有名词
- 科技术语、学科名、机构名、人名地名：同一篇内**统一**，首次出现给全称并可附原文。
- 不把口语词、网络词当术语；不把不同概念混用同一个词。
- 外文人名、作品名按通行的中文译名，必要时附原文。

## 3 标点（第十讲）

**硬规则（违反即必改）**
1. 禁止直引号（傻瓜引号）`"` `'`；中文用 “ ” ‘ ’，英文用 “ ” ‘ ’（半角）。
2. 中文内容用全角标点；纯英文内容用半角标点；中英混排须在**全文范围内统一**（推荐：公式/西文用半角，其余全角）。
3. 外文文字用半角标点，半角标点后加空格。
4. 顿号只用于并列词语；并列成分较长或带语气词时用逗号。
5. 并列成分用顿号、末尾接"等/等等"时，"等"前**不加**顿号（如"物理、化学、数学等"）。
6. 分句内部已用逗号，分句之间用**分号**；用分号隔开的并列分句不能被逗号统领。
7. 冒号用于提示下文或总括上文，一个句子里一般只用一个冒号；"说/道"后接引文用冒号。
8. 省略号为 **……**（六个点、占两字），不得写作"。。。"或"..."；省略号前一般不用点号，不与"等"并用。
9. 破折号为 **——**（占两字），破折号前通常不用点号，之后不紧跟点号（表示停顿延长时可接问号/叹号）。
10. 引号内外标点：引文独立完整时句末点号在引号内；引文作句子成分时不加句末点号；引文处于停顿处而引号内无点号时，点号在引号外。
11. 括号内外标点：句内括号（注释全句某词语）末尾不用句号，点号放在括号外；句外括号（注释整句/整段）内可用句号，括号外一般不用点号。
12. 序次语：一、/（一）/1./（1）/① 按层级递进；"第一""其次"后用逗号；不带括号的"一、二、"后用顿号；阿拉伯数字序次后用下脚点；加括号的序次语后不加点号。
13. 文章标题末尾一般不用标点（可用问号、叹号、省略号）。
14. "题为……""以……为题"：作品名用书名号，非特定作品的主题用引号。
15. 书名号只用于书名、篇名、报刊名、影视戏剧名、法规文件名等作品名；课程、栏目、活动、奖项等不用书名号。

**易错点**
- 问号、叹号叠用：两个叠用占一字位，三个叠用占两字位；问号与叹号连用占一字位。
- 连接号：短横线（-）用于复合词、代号；一字线（—）用于时间、地域起止；浪纹线（～）用于数值范围。
- 间隔号（·）：用于外国人名、书名与篇名之间、月份与日期之间。
- 点号不出现在行首（排版层面，二审有疑点可提示）。

## 4 数字与西文（第十讲·全半角符号、外文文字部分）

- 计量、统计、编号、日期一般用阿拉伯数字；概数、成语、惯用语用汉字（"三四个人""十之八九"）。
- 数值与单位之间按学科惯例留空格（如 318 m）；百分号、摄氏度紧排（如 25%）。
- 英文标题：第一个、最后一个及所有主要单词（名词、形容词、动词、副词、代词、从属连词）首字母大写；冠词（a/an/the）、介词（by/for/to 等）、并列连词（and/but/or）、两字母动词（is/be）不大写。
- 西文缩写首次出现给全称；同一缩写全文一致。
- 中西文之间、数字与中文之间按全文体例统一处理（有的刊物要求加空格，有的不加，本文档内须一致）。

## 5 输出要求

- `quote` 必须是原文的**连续片段**，长度以能唯一定位为准（一般 6–30 字），不要包含段首段尾之外的省略号。
- 错别字、标点类必须给 `before` 与 `after`；病句、用词类给出完整改后句或改后短语。
- 拿不准的（如作者刻意使用的风格化表达）不要报；确有问题但无法确定改法的，`action` 用 `comment_only`。
- 不要重复报告同一处；同一段同类问题过多时择要报告，并在 `problem` 中注明"同类问题另有多处"。
