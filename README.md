# ReSTAgent

**本地 AI 文稿审读工具**——在自己的电脑上完成「零审 → 一审 → 二审 → 三审」全流程，
按《文稿培训资料 V2.5.0》和《排版标准 260920》给出逐条意见，导出的 Word 带修订与批注。

- 全程本机运行，除调用你自己配置的模型 API 外不上传任何内容
- 不改动原文件，所有结果另存
- 支持一次排多份稿件
- 不需要安装第三方包（仅 Python 标准库 + 内置的 pypdfium2）

---

## 功能

| 环节 | 输入 | 查什么 |
|---|---|---|
| **零审** | Word | 录用把关：属性、立论、内容密度、难度、体例 |
| **一审** | Word | 内容与结构：学术错误、逻辑、文风、起标题、结构标注 |
| **二审** | Word | 文字与语法：病句、错别字、用词、标点、中西混排 |
| **三审** | IDML + PDF | 版式终审：页面尺寸、版面网格、字体字号、文字越界、字体混排 |

一~三审的意见都能在界面里逐条**接受 / 改写 / 忽略**，再导出 Word（带修订与批注）。
三审额外提供**页面图 + 红框定位**和 Markdown 报告。

## 快速开始

### 1. 启动

需要 **Windows + Python 3.10 及以上**。

双击 **`ReSTAgent.bat`**：先自检（打印 Python 版本、端口、浏览器探测结果），
通过后开一个无地址栏的独立窗口，关掉窗口服务即停。

命令行方式：

```bat
python -m app.desktop                  :: 桌面窗口
python -m app.desktop --selftest       :: 只自检，不开窗
python -m app.server --no-browser --log :: 纯服务 + 请求日志
```

### 2. 配置模型

点右上角 **设置**：

| 项 | 说明 |
|---|---|
| API Base URL | OpenAI 兼容地址，填到 `/v1` 为止，如 `https://api.deepseek.com/v1` |
| API Key | 只存在本机，只发给上面这个地址 |
| 各力度使用的模型 | 轻/标准/严格/极致 可分别指定 |
| 视觉模型 | **可单独配置** Base URL / Key / 模型，用于三审排版判读；留空则沿用主 API |
| 单块字数 | 默认 2800，稿件长可调大省调用 |
| 输出上限 max_tokens | 默认 32768；填 `0` 表示用服务端默认 |
| 导出正文字体 | 默认统一宋体，可跟随原稿或换字体 |
| 输入/输出单价 | 每百万 tokens 人民币价格，用于费用预估与结算显示 |

点「**测试连接**」会打印实际请求地址和每步状态码，失败时给出针对性建议。
点「**测试视觉模型**」会真发一张图，确认三审能否读图。

没填 Key 也能用：自动进入**本地规则预检**，用正则与词表查直引号、半角标点、的/地/得等硬性错误。

### 3. 一审 / 二审

1. 拖入或选择 `.docx`（可多选），或点「用示例稿件试一次」
2. 选环节（零审 / 一审 / 二审）与力度（轻 / 标准 / 严格 / 极致）
3. 点「开始审稿」，看进度与实时输出
4. 结果页逐条处理：接受 / 改写 / 忽略，可批量操作
5. 点「导出 Word」，得到带修订痕迹与批注的新文件

### 4. 三审（版式终审）

在 InDesign 里打开排好的文档，导出两份文件：

| 文件 | 导出方式 |
|---|---|
| **IDML** | 文件 → 导出 → InDesign 标记语言（.idml） |
| **PDF** | 文件 → 导出 → Adobe PDF（印刷），勾选「使用文档出血设置」 |

然后在软件里选「三审」环节，分别选择 IDML 与 PDF，点开始。

- 左侧是问题清单（必改 / 建议改 / 待核实），右侧是页面图
- 点某条意见，页面图跳到对应页并把红框滚到视野中间
- 「显示红框」可关掉，不挡内容
- 「− / ＋ / 适宽」缩放页面，页面图按 158dpi 渲染
- 右上「导出报告」得到 Markdown

> `.indd` 是闭源二进制格式，无法直接解析，**必须先导出 IDML**。

## 三审是怎么判的

### 角色判定（三层，逐级兜底）

字号和字体名分不清「作者名」和「节标题」，所以先给每段文字判**角色**，再套对应标准：

1. **视觉模型**：把 2 页拼成一张图，让模型看版面判断——哪块是正文、哪块是图注、哪块是装饰字。
   10 页只需 5 次调用，结果按文件缓存。
2. **IDML 框几何**：没有视觉模型时，用文本框的位置尺寸判断（贴底小字=编辑栏、很矮的块=图注、窄条=边栏）。
3. **字号 + 字体族名**：最后的兜底。

视觉失败会自动降级，不会卡住三审。

### 判定口径

- **以版面网格为准**：185×260mm、出血 3mm、2 栏、栏距 8mm、网格 9 点 / 行间距 7.5 / 22 字 38 行
- **页边距数值不参与判定**：网格起点会造成边距数值与标准表不一致，已确认网格正确
- **按角色分别判**：正文 9 点、节标题 12 点、图注 7.5 点、作者 12 点、编辑栏 6 点；
  首字下沉与装饰元素不套正文标准
- **拿不准的进「待核实」**：交人工判断，不臆断

### 规则可调

「规则库 → 排版要求（三审）」里能改：页面尺寸、出血、分栏、栏距、网格各项参数、
各角色字号行距、容差，以及 **15 条规则逐条开关**。改完保存，下次三审生效。
配置文件 `layout_rules.json` 存在用户目录，升级不覆盖。

## 数据存放

程序目录是只读的，用户数据都在用户目录：

| 平台 | 位置 |
|---|---|
| 首次运行 | 程序旁边有 `config.json` 则用 `user/`，否则 `%LOCALAPPDATA%\ReSTAgent` |
| 自定义 | 设置环境变量 `RESTAGENT_DATA` |

里面包括：`config.json`（含 API Key）、`data/`（上传原稿与导出结果）、
`third/`（三审任务与页面图）、`layout_rules.json`、`admin_secret.py`（管理员密码哈希）。

管理员密码在**首次运行随机生成**并打印到控制台，请登录「管理员」面板后立刻修改。

## 常见问题

**Q：提示 403 / blocked access based on your browser's signature？**
中转网关的 WAF 会拦 Python 默认 UA，程序已内置浏览器 UA；如果仍报错，多半是网关策略，换个端点或直连官方 API。

**Q：三审点了开始但很慢？**
视觉判定每张拼版（2 页）约 60~90 秒，10 页 5 张、3 并发约 3 分钟。重审同一份文件会命中缓存。
不想等可以在三审页取消勾选「先用视觉模型判定文字角色」，改为纯本地规则，几秒出结果。

**Q：导出的 Word 打开提示「发现无法读取的内容」？**
这是 Word 对自定义 XML 的严格校验，点「是」后内容正常并存为 .docx 即可。可把该提示反馈给开发者。

**Q：`py` 启动器指向了已卸载的 Python？**
用 `ReSTAgent.bat`，它会逐个实测可用的解释器。
